## ✨ Key Portfolio Features & Innovations

- 💎 **Liquid Glassmorphic UI & 100% Serif Headlines:** Built using Vanilla CSS glassmorphism (`backdrop-filter`), Playfair Display serif typography, and animated handwritten stroke underlines.
- 💊 **Horizontal Labeled Skill Rows with Unique Tap Animations:** 25+ technical skills categorized into 6 clean labeled rows with custom emojis and unique interactive tap micro-animations (`blink`, `sparkle`, `android-bounce`, `flame-flicker`, `3d-cube-flip`, `db-spin`).
- 📁 **Single-Row 4-in-1 Project Grid:** Fits all 4 production projects (`CNN Plant Classifier`, `GenAI Android App`, `Virtual Mouse Eye-Tracking`, `Android KPI Tracker with TFLite`) cleanly in a single horizontal row on desktop view.
- 🏷️ **Tactile Category Filter Highlights:** Filter buttons highlight with ambient cyan pill borders (`All Projects`, `ML & Computer Vision`, `Android App Dev`).
- 📄 **PDF Quick Preview Hub:** Open Resume & CV instantly inside an in-page Lightbox modal with Light/Dark Paper toggle support without forcing external file downloads.
- 🌊 **Translucent Liquid Theme Wave:** Smooth whole-screen radial theme wave expanding directly from the theme toggle icon position.
- 🎯 **100% Viewport Height Fitting:** Optimized layout spacing so every section heading and content card fits perfectly in 1 screen view without bottom cut-offs.

## 💻 Local Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sanjeevkumarmd/portfolio.git
   cd portfolio
   ```

2. **Serve locally using Python:**
   ```bash
   python -m http.server 8000
   ```

3. **Open in browser:**
   Navigate to `http://localhost:8000`

## 🌐 Deploying to GitHub Pages

To make your portfolio live at `https://sanjeevkumarmd.github.io/portfolio/`:

1. Go to your repository settings on GitHub: `https://github.com/Sanjeevkumarmd/portfolio/settings/pages`.
2. Under **Build and deployment** -> **Source**, select `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
